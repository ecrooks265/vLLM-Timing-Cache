# Historical pcache evidence

These are byte-preserved historical research files, excluding local terminal logs. Read ../docs/DEFENSE_BOUNDARY.md and ../docs/FINAL_RESULTS_zh.md for the current interpretation. Earlier notes include stronger or superseded claims, reversed AUC orientation, synthetic recovery batches and an unvalidated observer patch. They must not be treated as the conclusions of the new image study.

The original timing stopped at the first SSE chunk. New image timing uses first nonempty streamed content and drains the response before observing KV counters. Never pool the two protocols or treat them as a controlled cross-modality performance comparison. Legacy text and audio runs were not rerun in the new study. A README added for publication is intentionally outside the historical-file checksum manifest.
