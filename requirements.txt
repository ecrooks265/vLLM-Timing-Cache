# ── Harness (client) dependencies ────────────────────────────────────────────
# The measurement harness talks to the vLLM server over HTTP and never imports
# vLLM, so it installs cleanly in a plain CPU venv on any OS. vLLM itself runs in
# the server container (see docker/Dockerfile.rocm) and is NOT pinned here.
#
#   python -m venv .venv && source .venv/bin/activate
#   pip install -r requirements.txt
#
# (The old `vllm==0.6.3.post1` pin lived here to preserve block_size=1 for the
#  EarlyBird attack. On the ROCm/V1 path that pin is dropped — see README
#  "EarlyBird on ROCm". The server's vLLM version is set by VLLM_REF in the
#  Docker build.)
